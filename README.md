# Alterbake Akademia

Otwarta nauka rzemiosła piekarskiego i cukierniczego + test rozwoju osobistego
(Work Profile). Ucz się dobrowolnie, we własnym tempie.

- **`/`** — panel nauki: rzemiosło piekarza i cukiernika, rozwój, higiena,
  przedsiębiorczość. Postęp zapisuje się lokalnie w przeglądarce.
- **`/test/`** — test Profil Pracy / Mapa Potencjału.

Wersja publiczna, uogólniona. Treść operacyjna konkretnej piekarni pozostaje
prywatna. Statyczna aplikacja (Vite build) — serwowana z GitHub Pages.

Budowana z prywatnego monorepo `alterbake-ai-dashboard` skryptem
`tools/build-akademia.mjs` (filtr + neutralizacja + skan bezpieczeństwa).
