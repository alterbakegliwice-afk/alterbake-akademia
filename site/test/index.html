⚙ Synchronizacja z Google Sheets
Krok 1 — Utwórz arkusz i skrypt

Otwórz nowy Google Arkusz, kliknij Rozszerzenia → Apps Script, wklej poniższy kod i kliknij Wdróż → Nowe wdrożenie → Aplikacja internetowa. Ustaw dostęp: Wszyscy. Przy pierwszym uruchomieniu Google poprosi o zgodę na wysyłanie e-maili w Twoim imieniu — zatwierdź. Skopiuj wygenerowany URL. Po każdej zmianie skryptu wdróż ponownie (Wdróż → Zarządzaj wdrożeniami → edytuj → nowa wersja).

function doPost(e){
  var ss=SpreadsheetApp.getActiveSpreadsheet();
  var sheet=ss.getSheetByName('Wyniki v2')||ss.insertSheet('Wyniki v2');
  var data=JSON.parse(e.postData.contents);
  var email=data.email||'';
  var reportHtml=data.reportHtml||'';
  var name=(data.name||'Uczestnik').slice(0,40);
  delete data.reportHtml;
  if(sheet.getLastRow()===0){
    sheet.appendRow(Object.keys(data));
    sheet.getRange(1,1,1,Object.keys(data).length)
      .setFontWeight('bold').setBackground('#f3f0ea');
  }
  var headers=sheet.getRange(1,1,1,sheet.getLastColumn()).getValues()[0];
  sheet.appendRow(headers.map(function(h){return data[h]!==undefined?data[h]:''}));
  if(email&&reportHtml){
    try{
      // Native HTML->PDF conversion. Needs only the Gmail send scope — no Drive API,
      // no OAuth token juggling, which is what used to fail silently.
      var pdf=Utilities.newBlob(reportHtml,'text/html','Mapa_Potencjalu_'+name+'.pdf')
        .getAs('application/pdf').setName('Mapa_Potencjalu_'+name+'.pdf');
      MailApp.sendEmail({to:email,subject:'Twój wynik — Mapa Potencjału AlterBake',
        body:'W załączniku PDF z Twoim raportem z Mapy Potencjału. Jeśli PDF się nie otwiera, treść raportu jest też poniżej.',
        htmlBody:reportHtml,attachments:[pdf],name:'AlterBake OS'});
    }catch(err){
      // If PDF conversion is unavailable for any reason, still deliver the report inline.
      MailApp.sendEmail({to:email,subject:'Twój wynik — Mapa Potencjału AlterBake',
        htmlBody:reportHtml,name:'AlterBake OS'});
    }
  }
  return ContentService.createTextOutput('ok').setMimeType(ContentService.MimeType.TEXT);
}

Zasady testu

  • Oceń każde stwierdzenie na skali od „Zdecydowanie tak" po „Zdecydowanie nie" (5 stopni).
  • Nie ma odpowiedzi lepszych ani gorszych — różnicują styl, nie jakość.
  • Odpowiadaj na podstawie tego jak zazwyczaj działasz, nie jak chciałbyś/abyś działać.
  • Dane zostają wyłącznie na tym urządzeniu. Nie są wysyłane nigdzie.
  • Czas: ok. 14–18 minut. W razie sprzecznych odpowiedzi pojawią się dodatkowe pytania doprecyzowujące.
